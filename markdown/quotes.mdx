# Quotes project
## Why?
The reason why i created this project is because me and my friends say a lot of random / wierd stuff (very quirky I know). I thought it would be fun to store the quotes in some way and make them accessable / createable in some way shape or form. Originally I posted all of the quotes on Twitter.com but I found it a bit *out of place* because there are some unhinged sentences.

This project consists of multiple smaller applicatons that combine the whole project as a whole. I have made the **C#** Backend in Combination with a **MongoDB** Database, A **Nextjs** frontend and a **Java** discord bot.

## Backend

I started off with creating the backend of the project and setting up a MongoDB database. For the backend i used C# as stated before and i started making the REST API. This is the project structure that i set up and that i used for the project

```
quotes-backend/
├── DAL             # Data Access Layer
├── DTO             # Data Transfer Object(s)
├── Factory         # Providing the DAL
├── Interface
├── Logic
└── quotes-backend  # swagger UI
```

There are small descriptions per function on what it does. As you might have seen, there is a **Requires AUTH** text in the **POST** method, I implemented this because otherwise everyone would be able to update the database and that is just inconvenient. The authentication returns a JWT token if the credentials are correct. Once the JWT is returned and the user uses this token, they will be able to update, insert and delete records if needed.

### Endpoints

There are a few endpoints available in this API. These endpoints are mostly CRUD-like endpoints to save said quotes. There are different categories for the quotes such as *quotes*, *rizz* (charisma) and *insults* and there are other miscellaneous endpoints such as *Markov*, *LonerTime* and *Auth*.

Regarding the quote related endpoints, The differences between the names serves as categories for said quotes. In most cases the *quotes* endpoint is used to save the quotes and the other 2 are a nice to have for specific quotes. The amount of quotes below show the quotes saved per type:
